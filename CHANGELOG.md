# Changelog

## 0.1.0 - 2026-09-19

Initial public release.

- Responsive Crossplane trace tree with asynchronous refresh and cancellation.
- Adaptive ordinary-resource and package table layouts.
- Find, filter, collapse, selection reconciliation, and previous-trace diffs.
- Native Kubernetes YAML, Events, pause, unpause, delete, and finalizer actions.
- Captured `kubectl describe` and permanent `kubectl edit` support.
- UID and resource-version safeguards for mutations.
- A dedicated missing-resource state that clears stale traces and stops polling.
- Configurable themes, terminal-safe rendering, and Secret payload redaction.
- Linux and macOS release archives for amd64 and arm64.
